# タイムライン探索・選択の改修仕様

## 1. 目的

人生タイムライン上のイベントや目標を迷わず探し、概要を素早く確認し、選択した項目の説明を安定して読めるようにする。マーカーが密集するケース、スマートフォン、キーボード操作でも同じ情報に到達できることを目指す。

本書は改修仕様と実装状況を記録する。プロダクト要件を変える機能（データ編集、設定の永続化、年齢軸の変更など）は対象外とする。

## 2. 現状と対象範囲

### 現状

- `src/app/components/Timeline.tsx` が0〜100歳のタイムラインを幅1400pxで描画し、年齢に対応する横位置にイベントと目標を配置している。
- 項目は年齢順に描画され、密集を避けるため縦方向にレーンを分けている。
- マーカーのホバー・フォーカス時に概要カードを表示し、クリックまたはタップで選択するとタイムライン下に説明を表示する。選択中の項目を再度選択すると解除する。
- タイムラインはネイティブの横スクロール領域であり、Tabキーでフォーカスできる。
- 概要カードは幅200pxでマーカーの下に表示される。レーン割当てはマーカー間の距離で決まり、カードの幅・他のマーカーとの重なりは考慮されない。
- 選択後の説明領域は名称と説明を表示するが、年齢・カテゴリ・目標状態や明示的な閉じる操作は含まない。

### 対象ファイル

- 主な改修対象: `src/app/components/Timeline.tsx`
- 必要に応じてテストを追加・更新: `__tests__/` 以下のタイムライン関連テスト
- 仕様の反映先: 必要に応じて `docs/設計書.md` のタイムライン項目の記述

## 3. 改修方針

1. 年齢とマーカーの位置関係、イベントと目標の形、経過済み／これからの区別、寿命目安の値と線種、年齢入力・進行度の挙動を維持する。
2. 既存のネイティブ横スクロールを残し、追加操作は現在のスクロール動作を妨げない補助とする。
3. 「概要のプレビュー」と「項目を選択した後の詳細」を明確に分ける。説明の確認をホバーだけに依存させない。
4. 同じ内容を色だけで区別しない。既存のダークモード配色を変更しない。
5. マーカーの年齢上の位置は、レーン調整やプレビュー表示位置の都合で左右にずらさない。

## 4. 推奨する操作・表示仕様

### 4.1 タイムラインの移動

- 横スクロール可能な領域を維持する。マウス・タッチ・キーボードによる既存の横スクロールを引き続き利用できるようにする。
- 領域の直前に、次の年齢位置へ移動する補助ボタンを設ける。
  - **0歳へ**
  - **現在年齢へ**
  - **100歳へ**
- 「現在年齢へ」は現在年齢の目印が表示領域内に収まり、前後の年齢軸も少し確認できる位置までスクロールする。年齢が0歳または100歳に近い場合は、スクロール可能範囲に収める。
- ボタンはタイムライン領域外に置き、タイムライン内のマーカーや縦スクロールを覆わない。初期スクロール位置は現状の0歳側を維持し、自動移動は行わない。
- 移動時はタイムラインの横スクロール位置だけを更新し、ページ全体の縦スクロール位置は意図せず変えない。
- スクロール位置を動かしても、選択中の項目と詳細パネルは維持する。
- `prefers-reduced-motion` が有効な場合は、移動時に滑らかなアニメーションを使わない。通常時も移動は短くし、連続操作を妨げない。

### 4.2 マーカーのプレビュー

- マーカーへのポインタホバーまたはキーボードフォーカスで、対象1件の概要だけを表示する。現在の概要情報（名称・年齢・カテゴリ・目標状態）を維持する。
- タッチ端末では、マーカーのタップで項目を選択し、同時に選択中状態と詳細を表示する。ホバーを前提とした操作を要求しない。
- プレビューはタイムラインの表示範囲を越えないよう左右端で位置を調整する。近接するマーカーを隠す配置になる場合は反対側へ表示するか、簡潔な表示に切り替える。
- 概要カードの表示を操作条件にせず、選択中の項目は詳細パネルでも特定できるようにする。
- マーカーのラベル・フォーカス対象は引き続き個々の項目に対応させる。レーンの表示順とキーボードのフォーカス順は年齢順とする。

### 4.3 項目の選択と詳細パネル

- マーカーを選択すると、タイムラインの直後に詳細パネルを表示する。モーダルではなくページ内の領域とし、タイムラインの横スクロール領域内には配置しない。
- 詳細パネルには以下を表示する。
  - 項目名（パネルの見出し）
  - 年齢
  - 種別（イベント／目標）
  - カテゴリ
  - 目標の場合は状態
  - 説明。未入力の場合は「説明はありません。」と表示する
- 選択中のマーカーは、既存の形状・塗り分けを保ったうえで、フォーカスリングに似た輪郭や枠などの追加表現で識別できるようにする。選択状態を拡大・色だけで示さない。
- 別のマーカーを選ぶと、同じ詳細パネルの内容を新しい項目に置き換える。現在選択中のマーカーを再度選択するかパネル内の「閉じる」を押すと選択を解除する。
- 「閉じる」を押した場合は、操作を開始した選択マーカーへフォーカスを戻す。マーカーを再選択して閉じた場合は、マーカー上のフォーカスを維持する。
- 説明領域には適切な見出しとラベルを付ける。項目変更を支援技術へ通知する場合、詳細全体を毎回重複して読み上げないよう、変更内容に応じて通知範囲を調整する。

### 4.4 密集マーカーと表示端

- すべてのマーカーは正確な年齢位置を保ち、垂直方向のレーンで重なりを避ける。
- レーン割当て時にはマーカー同士の間隔を確保し、同一年齢や隣接年齢の項目も個別に選択できるようにする。項目順は年齢、元データ順で安定させる。
- 概要カードは同時に複数表示しない。カードが近くの別マーカーを隠す場合は、カード位置を調整し、カード自体がポインタ操作を妨げないようにする。
- 0歳・100歳のマーカー、現在年齢ラベル、寿命目安の線が重なる場合も、マーカーが領域外へ切れず、ラベル同士が読めることを確認する。
- 項目数が多い場合は必要な分だけ縦方向の高さを増やす。マーカーをまとめて一つに置き換えたり、年齢位置を変えたりしない。

### 4.5 狭い画面・タッチ操作

- 年齢軸の全体幅は維持し、スマートフォンでも横スクロールで0〜100歳を閲覧できるようにする。
- 画面幅が狭い場合も移動ボタンはラベルを認識でき、タップ可能な大きさを確保する。ボタン群が折り返す場合でもタイムラインとの前後関係を保つ。
- マーカーのタップ領域は視覚上のマーカーより十分大きく保ち、隣り合うマーカーを誤って選択しない間隔を確認する。
- タッチ操作で選択したときは詳細パネルを表示し、ポインタホバー専用の手順を残さない。
- 端末の縦スクロールと年齢軸の横スクロールをどちらも阻害しない。横スクロール中にマーカーを誤って選択しないことを実機相当のタッチ操作で確認する。

## 7. 変更しないこと

- 0〜100歳の時間軸、固定幅のスケール、年齢に対応するマーカー位置
- イベントを丸、目標をひし形で示す表現
- 経過済み／これからの塗り分け、平均寿命・健康寿命の値と凡例
- 現在年齢・性別の変更が画面表示へ反映される既存動作
- CSVから読み込んだイベント・目標を追加・編集しない仕様
- ダークモードの既存配色
