# 人生可視化アプリ 要件定義書

## 1. 文書の目的

人生の出来事や目標を時間軸上に並べ、これまでの歩みや今後の予定を視覚的に把握するアプリの要件を整理する。

本書では、現時点で共有されている内容を初期要件として記録する。未決定の事項は「検討事項」に一問一答形式で列挙し、回答を受けて順次確定する。

画面構成や内部構造などの設計内容は、本書とは別の設計書で扱う。

## 2. アプリの概要

人生の時間軸を横線のグラフとして表示し、その線上にイベントや目標を配置する。カテゴリ別に横棒グラフを表示する案もあるが、初期要件として採用するかは未決定とする。

初期段階では、リポジトリ内に置いたCSVファイルからサンプルデータを読み込み、画面に表示することを想定する。

## 3. 確定している要件

### 3.1 表示

- 人生を表す横方向の時間軸を表示する。
- 時間軸上にイベントや目標を配置する。
- リポジトリ内のCSVファイルからサンプルデータを読み込み、表示する。

### 3.2 カテゴリ別表示案

- 仕事や家族など、カテゴリごとの横棒グラフを別に表示する案がある。
- この表示を採用するか、カテゴリの種類や時間軸との関係は検討事項とする。

### 3.3 ダークモード

- 既存のダークモード切替機能を残す。
- ダークモード切替に伴う配色は、現在の配色から変更しない。

### 3.4 既存機能の扱い

- 現行アプリのテンプレート由来の機能は、今後の実装時に削除してよい。
- ダークモード切替機能は削除対象に含めない。
- 本タスクの変更範囲は要件定義書の作成に限り、アプリ本体の実装・削除は行わない。

## 4. 初期データに関する前提

- 初期表示用のサンプルデータは、リポジトリ内のCSVファイルを使用する。
- CSVのファイル名、配置場所、文字コード、列定義、日付形式は未決定とする。
- CSVの内容は、実在する個人の機微な情報ではなく、画面確認用のサンプルとする。

## 6. 初期版の範囲

### 含めること

- 横方向の人生時間軸と、その上のイベント・目標表示
- リポジトリ内CSVを用いたサンプルデータの表示
- 既存の配色を維持したダークモード切替

### 未確定・対象外

- カテゴリ別横棒グラフの採否と詳細
- CSVの具体的な形式および項目
- 画面からのデータ編集機能
- 検討事項で回答待ちとなっている振る舞い
- 本タスクでのアプリ本体の変更
